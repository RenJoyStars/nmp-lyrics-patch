Neural Mix Pro · 中文歌词版（安装说明）
=====================================

这是给劳老师那台 Mac 用的版本：在原版 Neural Mix Pro 上加了「中文界面 + 独立歌词窗」。
安装包已经把整个 App 打进去了，不用另外装原版。


★★★★★ 第一步：不要双击，请「右键 → 打开」 ★★★★★
=====================================================

这个包没有苹果开发者签名，所以双击一定会被 macOS 拦下来，
弹窗写着「无法打开，因为 Apple 无法检查其是否包含恶意软件」。
**这不是文件坏了，是正常的。**

正确做法只有一步之差：

    在 pkg 文件上点【右键】（触控板双指点击）
    → 菜单里选【打开】
    → 弹窗里再点一次【打开】
    → 输入这台 Mac 的管理员密码

如果照上面做了，弹出来的却是「已损坏，应移到废纸篓」，
那就打开「终端」，把下面这一行整行复制进去回车（会问密码，输入时不显示字符，输完回车）：

    sudo installer -pkg ~/Downloads/Neural*.pkg -target /

（这行用了通配符，pkg 文件名里带版本号也不用改。
 如果提示找不到文件，说明 pkg 不在「下载」文件夹 —— 先把它拖进「下载」再跑这行。）


★★★★★ 第二步：确认到底装上没有 ★★★★★
=======================================

装完打开 Neural Mix Pro，看这两处任意一处：

  ① 标题栏右侧最左边，有没有一个「气泡」形状的按钮？
     有 → 装上了。
     没有 → 没装上（回到第一步重做）。

  ② 更准的办法：
     在「应用程序」里找到 Neural Mix Pro → 右键 → 【显示包内容】
     → 打开 Contents → 打开 Frameworks
     → 里面有一个 libNMPLyrics.dylib 文件就是装对了。
     如果没有这个文件，说明装进去的还是原版。

很多「补丁没生效」的情况，其实是 pkg 被系统拦下、压根没装进去，
而屏幕上看起来像是装过了。


★★★★★ 第三步：怎么用歌词窗 ★★★★★
===================================

· 打开 Neural Mix Pro 后，标题栏右侧最左边那个「气泡」按钮 = 显示 / 隐藏歌词窗
· 也可以按 ⌘L
· 歌词窗是独立窗口：可以拖到投影仪那块屏，也可以拉伸放大
· 字号跟着窗口自动变，窗口拉大歌词就变大
· 右下角有个小滑条：整体放大 / 缩小字号（0.6×–2.0×，以窗口自动字号为基数），
  拖完会记住，下次打开还是这个倍率


【适用系统】
macOS 11 Big Sur 及以上；Intel 和 Apple 芯片（M 系列）都能装。


【歌词从哪来】
自动读取音乐文件里自带的内嵌歌词（网易云、QQ 音乐、酷狗、酷我、咪咕等下载的
mp3 基本都带）。播放哪首就同步哪首，不用手动导入。


【新歌第一次播放会卡一下，正常】
Neural Mix Pro 第一次播放某首歌时要先「分析分轨」（把人声 / 鼓 / 贝斯分开），
CPU / GPU 会吃满，这时拖进度条、开关窗口可能会顿一两秒。
等分析完（波形显示出来）就完全流畅了，分析结果会缓存，下次播放不再卡。


【几点说明】
· 界面文字已汉化：分轨名（人声 / 和声 / 贝斯 / 鼓）、曲库表头（曲目 / 艺人 / 调性 / 速度）、
  导出、1 轨 / 2 轨、显示波形等。
· 顶部菜单栏的 File / Edit / View 等**大标题**仍是英文（App 内部写死，改不了）；
  点开以后里面的条目是中文。
· 中文界面要系统语言是「简体中文」才显示。
  如果界面还是英文，但标题栏有气泡按钮 —— 那是系统语言的问题，不影响歌词窗使用。
· 如果这台 Mac 原来装过正版 Neural Mix Pro，安装会覆盖它，建议先把原 App 备份一份。
· 卸载：把「应用程序」里的 Neural Mix Pro 拖到废纸篓即可，不写系统其他位置。
