Neural Mix Pro · 中文歌词版（安装说明）
=====================================

这是给劳老师的一台 Mac 用的版本：在原版 Neural Mix Pro 上加了“中文界面 + 独立歌词窗”。
安装包已经把整个 App 打进去了，不需要另外装原版。

【适用系统】
macOS 11 Big Sur 及以上；Intel 和 Apple 芯片（M 系列）都能装。

【安装步骤】
1. 双击 “Neural Mix Pro 歌词版.pkg”
2. 如果提示“无法打开，因为无法验证开发者”：
   在文件上点右键 → 打开 → 再点“打开”；
   或到「系统设置 → 隐私与安全性」，页面下方点“仍要打开”。
3. 一路“继续 / 安装”，装完点“关闭”。

【怎么用歌词窗】
· 打开 Neural Mix Pro 后，标题栏右侧最左边那个“气泡”按钮 = 显示/隐藏歌词窗
· 也可以按 ⌘L
· 歌词窗是独立窗口：可以拖到投影仪那块屏，也可以拉伸放大
· 字号跟着窗口自动变，窗口拉大歌词就变大
· 右下角有个小滑条：整体放大/缩小字号（0.6×–2.0×，以窗口自动字号为基数），
  拖完会记住，下次打开还是这个倍率
· 右下角有个小滑条：整体放大/缩小字号（0.6×–2.0×，以窗口自动字号为基数），
  拖完会记住，下次打开还是这个倍率

【歌词从哪来】
自动读取音乐文件里自带的内嵌歌词（网易云、QQ 音乐、酷狗、酷我、咪咕等下载的
mp3 基本都带）。播放哪首就同步哪首，不用手动导入。

【新歌第一次播放会卡一下，正常】
Neural Mix Pro 第一次播放某首歌时要先“分析分轨”（把人声/鼓/贝斯分开），
CPU/GPU 会吃满，这时拖进度条、开关窗口可能会顿一两秒。
等分析完（波形显示出来）就完全流畅了，分析结果会缓存，下次播放不再卡。

【几点说明】
· 界面文字已汉化：分轨名（人声/和声/贝斯/鼓）、曲库表头（曲目/艺人/调性/速度）、
  导出、1 轨/2 轨、显示波形等。
· 顶部菜单栏的 File / Edit / View 等**大标题**仍是英文（App 内部写死，改不了）；
  点开以后里面的条目是中文。
· 如果这台 Mac 原来装过正版 Neural Mix Pro，安装会覆盖它，建议先备份原 App。
· 卸载：把“应用程序”里的 Neural Mix Pro 拖到废纸篓即可，不写系统其他位置。
